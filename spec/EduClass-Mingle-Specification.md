# EduClass Mingle — Product Specification

## 1. Project Overview

**Name:** EduClass Mingle

**Description:** An application that combines Instagram and StudyStream into one platform.

**Purpose of this document:** Complete, structured documentation of every feature described in the original brainstorm. No feature has been added, modified, improved, or omitted.

---

## 2. Core Concept

EduClass Mingle merges a solo/group studying platform with a social media platform (modeled exactly on Instagram) into a single application. The application is composed of seven systems:

1. Solo Study System
2. Pomodoro System
3. Notes System
4. Group Study System
5. Social Media System
6. Coin System
7. Profile Customization System

---

## 3. Solo Study System

### 3.1 Modules
- A user can create the modules they want to study.

### 3.2 Per-Module Actions
For every module, the user can:
- Add PDFs
- Add study sources

### 3.3 AI Assistant (per module)
Every module has an AI assistant capable of generating from those PDFs:
- Flashcards
- Quizzes
- Question & answer practice
- A complete résumé/summary of the PDFs

No other AI capability exists beyond these four.

### 3.4 Scope
The module is the place where all studying happens.

---

## 4. Pomodoro System

- The application includes a Pomodoro timer.
- The timer is represented by a cute avatar.

### 4.1 During Study Sessions
- The avatar hops around the screen.
- The avatar runs.
- The avatar plays while the user studies.

### 4.2 During Break Mode
- The avatar stops studying.
- The avatar takes a break.

---

## 5. Notes System

- The application contains a place where users can write their notes.
- No markdown support, folders, synchronization, or any other additional feature is included.

---

## 6. Group Study System

- Users can join rooms and servers.

### 6.1 Inside Rooms, Users Can:
- Video call
- Study together
- Communicate through calls
- Share notes
- Share summaries (résumés)

### 6.2 Explicit Exclusions
- No screen sharing
- No whiteboards
- No moderation systems
- No permissions systems

---

## 7. Social Media System

- The application also contains a social media section.
- It works exactly like Instagram.

### 7.1 Included Features
- Posts
- Pictures
- Videos
- Captions
- Comments
- Friends
- Stories

### 7.2 Explicit Exclusions
- No reels
- No hashtags
- No explore page
- No messaging
- No trending
- No likes
- No bookmarks

---

## 8. Coin System

### 8.1 Earning Coins
Users earn coins by:
- Studying
- Staying inside the application

### 8.2 Spending Coins
- Coins can be spent to customize their profile.

No additional methods of earning or spending coins exist.

---

## 9. Profile Customization System

- The profile is NOT a normal social media profile.
- Instead, it looks like an empty room.
- Users decorate that room using accessories purchased with coins.

---

## 10. User Flow

Based strictly on the systems described above, a user's path through the application touches:

1. Enter the application.
2. Solo study: create modules, add PDFs/study sources, use the module's AI assistant (flashcards, quizzes, Q&A practice, résumé/summary).
3. Use the Pomodoro timer while studying (avatar hops/runs/plays) and during breaks (avatar takes a break).
4. Write notes in the Notes system.
5. Join rooms/servers for group study: video call, study together, communicate through calls, share notes, share résumés.
6. Use the Social Media section: create/view posts, pictures, videos, captions, comments, friends, stories.
7. Earn coins by studying and staying inside the application.
8. Spend coins to customize the profile (the "room").
9. Decorate the profile room with purchased accessories.
